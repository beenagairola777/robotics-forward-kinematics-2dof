# Forward Kinematics of a 2-Link Planar Robotic Arm

## Overview
This project implements forward kinematics for a 2-degree-of-freedom (2-DOF) planar robotic manipulator. The end-effector position is computed using joint angles and link lengths and visualized in Cartesian space.

## Problem Statement
Forward kinematics is a core robotics concept used to determine the pose of a robot's end effector from joint parameters. This project demonstrates joint-space to task-space transformation for a serial manipulator.

## Methodology
- Defined link lengths and joint angles
- Computed joint positions using trigonometric kinematic equations
- Calculated end-effector coordinates
- Visualized the robotic arm configuration

## Technologies Used
- Python
- NumPy
- Matplotlib

## Key Learning Outcomes
- Serial manipulator kinematics
- Joint-to-end-effector transformation
- Foundation for inverse kinematics and robot control
